# 피카츄 모래시계 ⚡

HTML, CSS, JavaScript로 만든 간단한 포켓몬 모래시계 타이머입니다.

- 1분 · 3분 · 5분 · 10분 선택
- 시작, 일시정지, 이어하기, 초기화
- 남은 시간에 맞춰 줄어드는 모래 애니메이션
- 모바일 화면 및 모션 감소 설정 지원

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

로컬 서버를 사용하려면:

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속하세요.
